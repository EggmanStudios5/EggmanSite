Guide 01 · Macro Pad Desktop App

Install Python & Connect Your Macro Pad

Choose your operating system below for the exact steps to install Python, open the configurator, and save your shortcuts.

1. Install Python 3

Download Python from python.org (or run the command below). When the installer opens, check the box at the bottom that says "Add python.exe to PATH" and click Install Now.

Terminal / Command Prompt 
winget install -e --id Python.Python.3.12

2. Download the App & Install the 2 Required Libraries

Open Command Prompt or PowerShell, download the Macro folder, and install `pyserial` (for USB communication) and `keyboard` (for recording key presses):

Terminal / Command Prompt 
git clone https://github.com/FilipVastl005/Macro.git
cd Macro
python -m pip install pyserial keyboard

3. Plug In Your Pad & Open the App

Plug your Macro Pad into a USB port, then start the app:

Terminal / Command Prompt 
python macro_pad_config.py

4. Connect & Assign Your Keys

In the app window: click "🔄 Refresh", choose your COM port (like COM3 or COM4) from the dropdown, and click "✔️ Connect". Click "📝 Program Buttons", assign each key, and hit "💾 Save to Device". Once it says updated, you can close the app—your shortcuts are saved inside the pad.

Helpful Tip (Windows 10 / 11): Not sure which COM port is your pad? Unplug the USB cable, click Refresh to see which port disappears, then plug it back in and click Refresh again.

1. Install Python 3 & Tkinter

On Linux, the window library (`tkinter`) is a separate package. Install it with your package manager:

Terminal / Command Prompt 
# Ubuntu / Debian / Mint:
sudo apt update && sudo apt install -y python3 python3-pip python3-tk python3-venv git

# Fedora:
sudo dnf install -y python3 python3-pip python3-tkinter git

# Arch Linux:
sudo pacman -S --needed python python-pip tk git

2. Allow USB Port Access (One-Time Step)

Add your user account to the serial port group so you can connect to `/dev/ttyACM0` without permission errors. Log out and log back in once after running this:

Terminal / Command Prompt 
# Ubuntu / Debian / Fedora:
sudo usermod -a -G dialout $USER

# Arch Linux:
sudo usermod -a -G uucp $USER

3. Download the App & Install Libraries

Download the Macro folder, create a small virtual environment, and install `pyserial` and `keyboard`:

Terminal / Command Prompt 
git clone https://github.com/FilipVastl005/Macro.git
cd Macro
python3 -m venv .venv
source .venv/bin/activate
pip install pyserial keyboard

4. Open the App & Save Your Keys

Plug in your Macro Pad, launch the app, select `/dev/ttyACM0`, click "✔️ Connect", set your shortcuts, and click "💾 Save to Device":

Terminal / Command Prompt 
./.venv/bin/python macro_pad_config.py
Helpful Tip (Linux (Ubuntu / Debian / Fedora / Arch)): In the key assignment popup, you can either press a shortcut on your keyboard or simply type it into the text box (e.g. CTRL+C or ALT+TAB) and click OK.

1. Install Python 3 & Tkinter

Install Python and `python-tk` using Homebrew (or download the universal macOS installer from python.org):

Terminal / Command Prompt 
brew install python python-tk git

2. Download the App & Install Libraries

Open Terminal, download the Macro folder, and install `pyserial` and `keyboard`:

Terminal / Command Prompt 
git clone https://github.com/FilipVastl005/Macro.git
cd Macro
python3 -m venv .venv
source .venv/bin/activate
pip install pyserial keyboard

3. Plug In Your Pad & Run the App

Connect your Macro Pad via USB and start the app:

Terminal / Command Prompt 
./.venv/bin/python macro_pad_config.py

4. Select USB Port & Save Keys

Pick the `/dev/cu.usbmodem...` port from the dropdown, click "✔️ Connect", then click "📝 Program Buttons". Assign your 9 keys and click "💾 Save to Device".

Helpful Tip (macOS): If macOS asks for "Input Monitoring" permission when capturing key presses, you can either allow Terminal in System Settings -> Privacy & Security, or just type your shortcut (like CTRL+C) into the popup box.
Guides 02–04 · Hardware Assembly & Mounting

Connecting & assembling your hardware

Simple 4-step checklists for assembling a DIY Macro Pad, setting up a Mateo Weather Station outside, or installing an RFID door lock.

Guide 02 · DIY Macro Pad Kit

How to Assemble & Flash a DIY Macro Pad

Bought bare switches and a microcontroller from the shop? Follow these 4 steps to put it together.

1

Snap Switches into the Plate

Push your mechanical switches firmly into the top plate until they click, making sure the metal pins on the bottom aren't bent. Push your keycaps onto the stems.

2

Solder the 3×3 Switch Grid to the Board

Wire the 3 horizontal switch rows to pins 9, 8, and 7 on your Arduino Pro Micro / Leonardo. Wire the 3 vertical switch columns to pins 6, 5, and 4.

3

Upload the Firmware (Skip if Pre-Flashed)

If you bought our Pre-Flashed Microcontroller from the shop, skip this step! Otherwise, open Arduino IDE, install the "Keypad" library from Library Manager, open `3x3/simple/usb/simple.ino`, select "Arduino Leonardo" under Tools -> Board, and click Upload.

4

Screw the Case Together & Set Your Keys

Place the board into the bottom case, tighten the 4 corner screws, plug in the USB cable, and follow the Python guide above to set your shortcuts.

Guide 03 · Pre-Built & DIY Mateo Weather Stations

How to Mount & Connect Your Mateo Weather Station

Where to place your station outdoors, how to turn on the solar battery, and how to connect it to Wi-Fi or your indoor display.

1

Turn On the Internal Battery Switch

Unscrew the weatherproof cap on the bottom of the white louvered housing and flip the internal battery switch to ON. The small status light will blink twice to show the battery and sensors are awake.

2

Connect to Wi-Fi (or Plug In Your Indoor Display Hub)

For Urban Wi-Fi stations: hold the Setup button for 3 seconds, connect your phone or laptop to the "Mateo-Setup" Wi-Fi network, and enter your home Wi-Fi password at 192.168.4.1. For Long-Range LoRa stations: simply plug the indoor receiver screen into a USB power adapter inside your house—it is already paired to the outdoor mast.

3

Pick a Good Outdoor Spot (1.5m–2m High)

Mount the white radiation shield on a pole, fence post, or balcony rail about 1.5 to 2 meters off the ground where wind can blow freely through the vents. Avoid mounting it directly over black asphalt or right next to an air-conditioning exhaust.

4

Aim the Solar Panel South

Point the solar panel facing South (at roughly a 45° tilt) so it catches winter sun and sheds rain or snow. Give the air-quality sensor 24 hours outdoors to settle into a clean baseline reading.

Guide 04 · RFID Classroom & Workshop Door Kit

How to Install & Wire the RFID Door Access Kit

How to mount the reader in the hallway, keep the lock switch safe inside the room, and add student cards.

1

Mount the Reader Outside & Controller Inside

Screw the card reader box to the wall outside the classroom door, and mount the main controller box inside the locked room. Run a 4-wire cable (TX, RX, 5V, GND) through the doorframe to connect the two boxes.

2

Wire the Electric Door Strike (Inside the Room)

Connect your 12V electric door strike to the green relay screw terminals inside the room (Pin 4 on the inside board). Attach the included 1N4007 diode across the two door lock wires (silver stripe on the +12V wire) so the lock doesn't cause power spikes.

3

Flash the Two Boards (If Building from Scratch)

If you are using your own ESP boards instead of a pre-flashed kit, upload `esp/InputNode.ino` to the outside reader board (MFRC522 on pins 10 and 9) and `esp/OutputNode.ino` to the inside relay board.

4

Add Student Cards & Test the Door

Power on the inside controller and open the local room dashboard in your browser on the building Wi-Fi. Tap a new student card on the outside reader—it will show up in the log so you can approve it and test that the door unlocks for 3 seconds.
